# data/ について

`shizuoka-city-shelters.csv` は、国土地理院の「指定緊急避難場所データ」（静岡県）から、住所が静岡市の行（402件）だけを取り出したものです。列と値は変えていません。

## 出典とご利用上の注意

出典：[国土地理院「指定緊急避難場所データ」](https://www.gsi.go.jp/bousaichiri/hinanbasho.html)（静岡県のデータから、静岡市の402件を抜き出して加工）

国土地理院コンテンツ利用規約（https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html）と、次のご利用上の注意に従って使います。

1. 本データは、災害対策基本法第49条の4・第49条の7に基づき市町村長が指定した指定緊急避難場所・指定避難所の情報を各市町村に登録いただいたものです。なお、最新でない場合や未掲載の場合があるため、最新かつ詳細の状況などは必ず当該市町村にご確認ください。
2. 「指定緊急避難場所」と「指定避難所」の違いや、指定緊急避難場所が災害種別ごとに指定されていることを理解した上でご利用ください。
3. 本データは随時更新されますので、利用される場合は、ご注意ください。
4. 本データを用いた情報を第三者に提供する場合は、上記1．～3．の注意事項が正確に伝わるよう、十分にご留意ください。

アプリの画面の下（`frontend/components/DataNotice.tsx`）にも、出典と注意を出しています。

## 列と、DB の表の対応

| CSV の列 | DB の表と列 | メモ |
|---|---|---|
| NO | 使わない | 静岡県全体のファイルの中の通し番号。静岡市の行は1143から始まる |
| 共通ID | `shelters.id`（主キー） | 場所ごとに決まっている番号 |
| 施設・場所名 | `shelters.name` | |
| 住所 | `shelters.address` | 書き方はそろえていない |
| 洪水、崖崩れ、土石流及び地滑り、高潮、地震、津波、大規模な火事、内水氾濫、火山現象 | `shelter_hazards`（「1」の列だけ1行）と `hazards`（種類の8行） | |
| 指定避難所との住所同一 | `shelters.same_address_as_evacuation_center` | 「1」なら true |
| 緯度、経度 | `shelters.lat`、`shelters.lng` | |
| 備考 | `shelters.note` | 空欄は NULL |

なぜこう分けたかは、レッスンの解説ページ「避難場所データの表設計」にまとめています。

## データを新しくするには

1. 国土地理院のページで利用規約とご利用上の注意に同意し、静岡県の指定緊急避難場所の CSV をダウンロードします
2. 住所が「静岡県静岡市」で始まる行だけを残し、`shizuoka-city-shelters.csv` を置き換えます（1行目の列の名前は残します）
3. `npm run db:seed` で、DB の3つの表を作り直します
